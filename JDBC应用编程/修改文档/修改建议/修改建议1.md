# 任务五修改建议 1

**任务五已有 Java 源码、运行截图和功能测试记录。** 程序具备课程增删改查、多表查询、事务提交和回滚，已有重复主键及外键异常证据。本轮以 Java 17 为目标重新编译了 15 个 Java 源码及测试文件，`RulesTest` 通过。MySQL 集成测试结论引用仓库已有记录。依据[任务书第 5.2 节和最终提交规范](<../../../大模型辅助数据库设计与JDBC编程_课程大作业(2).docx>)、[运行说明与功能测试](../../说明与功能测试.md)和[业务测试记录](../../../CourseSelectionSystem/业务测试记录.md)。

## 建议优先修改

1. **修正运行说明和集成脚本的路径。** README、任务五运行说明与开发规则中保留了旧的 F 盘路径，`run_integration_test.py` 还直接调用 F 盘的 `java.exe`、`javac.exe`。建议从仓库内的项目根目录启动，用 `JAVA_HOME` 或 PATH 解析 JDK，把数据库初始化命令指向项目内 SQL，并写明 MySQL 实测版本、JDK 17 或以上、Connector/J 9.7.0 及建立 `coursework` 登录路径的步骤。README 开头的 `功能核对与实施进度.md` 在现有目录中找不到，可链接到实际维护的业务测试记录和运行说明。验收用当前 D 盘工作区从编译开始复跑。[README](../../../CourseSelectionSystem/README.md) [pom.xml](../../../CourseSelectionSystem/pom.xml) [隔离集成脚本](../../../CourseSelectionSystem/run_integration_test.py) [开发规则](../../../CourseSelectionSystem/任务五开发规则.md)

2. **补充课程条件查询。** 管理员课程菜单目前只列出全部课程。课程任务书第 5.2 节明确列出“按条件查询并显示结果”，其他多表查询已有按教师、班号等条件过滤。建议在现有课程 CRUD 中增加课程号查询，空输入仍可列表，并用 `PreparedStatement` 绑定查询参数。分别验证查到指定课程、无匹配和空输入的行为，同步更新功能测试第 3 节。[CourseDAO.java](../../../CourseSelectionSystem/src/main/java/edu/coursework/dao/CourseDAO.java) [Main.java](../../../CourseSelectionSystem/src/main/java/edu/coursework/Main.java) [运行说明与功能测试](../../说明与功能测试.md)

3. **补齐本人选课记录的绩点和退课详情。** 任务一的学生业务流程包含成绩和绩点，任务三规定在查询层派生退课类型。当前 `myRecords` 对有效记录只显示分数或“暂无成绩”，对退课记录只显示选课时间和退课状态。建议用 `Rules.gpa` 展示已录成绩的绩点，并在历史记录中展示北京时间退课时刻及按所属学期派生的常规或期中类型。分别核对已录 0 分、未录入、常规退课和期中退课。[任务一学生业务流程及 BR-09](../../../需求分析文档/高校教学管理系统_业务需求分析.md) [Main.java](../../../CourseSelectionSystem/src/main/java/edu/coursework/Main.java) [Rules.java](../../../CourseSelectionSystem/src/main/java/edu/coursework/util/Rules.java) [任务三关系模式清单第 4 节](../../../逻辑结构设计与规范化分析文档/关系模式清单.md)

4. **明确学生只能在窗口内使用余量筛选。** 学生菜单目前总是询问“只显示可选余量”，勾选后会跳过所有窗口外的教学班。如果当前所有班都过了窗口，选 `y` 只会看到空输出。建议普通浏览继续列出教学班并隐藏窗口外的名额数据，余量筛选仅作用于可选窗口内的班；当没有可用窗口时，隐藏筛选入口或明确提示。分别验证窗口内有余量、窗口内满员、窗口外普通浏览和窗口外尝试筛选。[任务一 FR-02、BR-05](../../../需求分析文档/高校教学管理系统_业务需求分析.md) [Main.java](../../../CourseSelectionSystem/src/main/java/edu/coursework/Main.java) [QueryService.java](../../../CourseSelectionSystem/src/main/java/edu/coursework/service/QueryService.java)

5. **把不存在的班号和真实空班区分开。** 管理员输入不存在的班号，名单可以直接空白，班级统计会显示全零，容易与真实存在但没有选课记录的空班混淆。教师姓名筛选无匹配也应给出提示。建议输出“教学班不存在”“暂无有效选课学生”“无匹配教学班”等对应结果，并保持教师查询本人任课班级的权限校验。分别输入不存在的班、存在的空班和无匹配的教师姓名复核。[任务一 FR-07](../../../需求分析文档/高校教学管理系统_业务需求分析.md) [QueryService.java](../../../CourseSelectionSystem/src/main/java/edu/coursework/service/QueryService.java)
