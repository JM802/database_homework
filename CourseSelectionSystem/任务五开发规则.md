# 任务五开发规则

## 项目与环境

- 使用已有 MySQL 数据库 `university_coursework`，表结构和测试数据以任务四的 SQL 脚本及实际数据库为准。已有数据库不重复初始化。
- 采用 Java 命令行程序，通过 JDBC 操作数据库，使用 Maven 管理依赖。
- 不要求安装 Java 或 IDE，不把 IDE 或指定 Java 版本作为本任务额外要求；按现有环境直接编写和运行代码。
- 项目代码放在仓库相对路径 `CourseSelectionSystem`。按实际环境确定编译、运行方式，并在项目 README 中写出可执行的命令。

## 数据库配置

- 本地数据库连接信息存放在 `CourseSelectionSystem/.env`，不写入 Java 源码或提交到 Git。
- 已按当前数据库配置准备 `.env`：主机 `localhost`，端口 `3306`，数据库 `university_coursework`，用户 `root`，密码使用用户提供的本地密码。实际连接地址、端口或用户名不同时按实际情况修改。
- 根目录 `.gitignore` 忽略 `CourseSelectionSystem/.env`。程序应读取该配置；需要共享配置格式时提供不含真实密码的示例文件。

## 功能与数据

- 至少完成一个核心实体的增删改查、两条多表查询、一个事务业务，以及常见数据库异常处理。功能实现以作业任务五要求、现有需求文档和实际表结构为依据。
- 涉及选课时遵循现有选课时间、重复选课、课程冲突和容量等规则，保证选课记录与教学班有效人数一致；失败时回滚。项目需求规定单用户顺序操作，不强制增加并发选课支持。
- 测试前确认测试数据及影响范围，避免覆盖或删除已有业务数据；测试结果根据实际运行记录，不虚构。

## 截图与交付

- 不生成或伪造运行截图。截图说明文档中写明实际操作和需要展示的结果，并留出截图位置，由用户之后自行截图。
- 提供 Java 源代码、README、真实功能测试记录及截图说明。涉及账号和密码的截图不得暴露凭据。
