# 任务一至四复核

| 范围 | 发现及处理 |
|---|---|
| 任务一，账号 | 需求稿包含指定管理员初始口令。任务四只存 32 字节测试哈希，运行证据不输出口令。任务五将按应用配置生成真实哈希并初始化，不应把凭据放进源代码。 |
| 任务一、二，学期 | 每个教学班按所属学期独立排课。小学期从春季开学后第 126 天开始，前 3 天可选退课。历史文档中的“第 1 周”以周日开始。本轮样本验证学年三学期齐备、实际日期互不重叠。 |
| 任务二、三，派生字段 | 概念模型仍有结束日、选课状态和退课类型。逻辑及物理模型从学期和退课时刻计算，保持相同的可查询语义。选课状态不和退课时刻分开写入。 |
| 任务一至三，删班与班号 | 按任务一删班需要删除班级关联数据，保留共享教室、时间、其他班和发号状态。任务三的计数表已建，现有最大班号不能作为下一号的唯一依据。直接删除有引用的基础资料会被外键拒绝。 |
| 任务三，事务边界 | 行 CHECK 无法核验跨行冲突、缓存准确性或改分权限。任务四用全库审计验证样本，任务五的 Java/JDBC 写入路径仍需在事务内检查这些规则。 |
| 任务四，查询执行错误 | Q08 首次执行报 MySQL 1052，课程基础表与统计结果存在同名连接列。改用限定别名的显式 ON，重新实际执行。 |
| 任务四，删班验证脚本 | 使用会话变量匹配班号时，连接默认排序规则与表排序规则不同，首次验证报 1267。会话设置与建表相同的排序规则后，删班和回滚验证通过。 |
| 任务四，初始化运行环境 | 现有系统连接在环境中不可访问。复用安装的 MySQL 8.0.41 二进制启动隔离实例，使用共享内存完成验证，无须安装第二份 MySQL。 |
| 任务四，真实可登录测试账号 | 本任务只验证账号字段、哈希长度和外键。任务五使用 PBKDF2 初始化账号之后，再执行真实登录测试。 |

验收覆盖四类基础完整性约束、样本量、八条语句按分类配额、半开选退课窗口、退课重选、春季与小学期边界、0 分与未录、合授统计、按班独立排课、异常 SQL 被拒绝以及复核时数据未变。
