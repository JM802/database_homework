# 高校教学管理系统数据库物理设计与 SQL 实现

> 本文根据首次提交 `be3e478` 保存的任务四 AI 方案和 SQL 整理。最新运行步骤见[物理实现说明](物理实现说明.md)。

## 1. 建库与索引

使用 MySQL 8.0.41 建立 `university_coursework` 数据库，共 14 张表。表使用 InnoDB，字符集为 `utf8mb4`，排序规则为 `utf8mb4_0900_as_cs`。设置主键、外键、唯一约束与非空约束，用 `CHECK` 约束班号格式、有效人数、选退课时间先后及分数范围等字段值。

在教师姓名和工号上建立联合索引，配合任课表按教师查教学班。为排课的教室和时间建立联合索引。选课记录分别建立以学号和班号开头的索引，用于个人修读史和班级名单查询。[01_create.sql](../CourseSelectionSystem/sql/01_create.sql)

## 2. 测试数据

给每张表准备至少 10 行数据。学期根据学年和学期号填入开学日期，教室按区、楼栋、楼层和房间尾号生成，共 2430 间。样本包含合授、同一班在两个时段使用不同教室、常规退课、期中退课、退课后重选及改分记录。成绩样本含 0 分和未录成绩两种情况。初始化时根据未退课的选课记录填入各班有效人数。[02_seed.sql](../CourseSelectionSystem/sql/02_seed.sql)

## 3. 八条 SQL 查询

| 编号 | 类型 | 查询内容 |
|---|---|---|
| Q01 | 单表条件查询 | 按名称前缀找 3 区 3 教一层的教室。 |
| Q02 | 单表条件查询 | 查春季容量不少于 18 人的班，按剩余名额排序。 |
| Q03 | 多表查询 | 用 `INNER JOIN` 查某个班的课程、上课时间和教室。 |
| Q04 | 多表查询 | 用 `LEFT JOIN` 查学生修读史，保留退课和未录成绩的记录。 |
| Q05 | 分组查询 | 用 `GROUP BY` 和 `HAVING` 找至少有两条选课记录的班。 |
| Q06 | 嵌套查询 | 用 `IN` 按任一合授教师姓名查班。 |
| Q07 | 嵌套查询 | 用 `EXISTS` 和 `NOT EXISTS` 找有有效选课但尚无成绩的学生。 |
| Q08 | 复杂查询 | 按课程和学期分别汇总选退课、任课和成绩，再连接各项统计。 |

[03_queries.sql](../CourseSelectionSystem/sql/03_queries.sql)

## 4. 执行与校验

先建表并导入测试数据，再执行查询并用 `COUNT(*)` 核对各表行数。运行样本审计，检查人数缓存、排课冲突和成绩记录等。试写重复主键、无效外键及越界分数，核对 MySQL 返回的错误。[04_audit.sql](../CourseSelectionSystem/sql/04_audit.sql)

首次执行完成建表与造数。Q08 在连接多个汇总结果时使用了未限定的同名课程编号，MySQL 报 1052。后续修改及重新运行结果见[人工修改记录](人工修改记录.md)和[MySQL 运行记录](运行证据/MySQL实际运行.txt)。
