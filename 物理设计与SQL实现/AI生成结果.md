# 高校教学管理系统数据库物理设计与 SQL 实现

> 本文保留本阶段的 AI 候选方案和初次执行问题。以[物理设计与运行说明](物理设计与运行说明.md)及最终 SQL 为准。

## 1. 背景与范围

根据任务三的 14 个关系创建 MySQL 数据库，建立完整性约束和索引。准备覆盖多学期、合授、退课、重选、未录成绩和改分历史的测试数据，编写分类查询。

## 2. 初步实现

| 模块 | 初步方案 |
|---|---|
| 建库 | 以班号、标识及联合主键保持任务三结构。用外键和行检查约束维护引用和字段域 |
| 测试数据 | 由学年和学期形成固定开学日期，教室按区、楼栋、楼层、房间尾号生成 |
| 查询 | 条件过滤两条，多表两条，分组一条，嵌套两条，复杂统计一条 |
| 运行 | 先建库并初始化，再逐条对照查询基准结果，同时验证非法写入被拒 |

## 3. 初次执行与修正

MySQL 首次运行通过建表与造数。复杂统计初稿把课程表加入后，仍通过未限定的同名课程列 `USING` 连接多个聚合结果，执行时报 1052。修订为带别名的 `ON` 连接条件。复杂统计仍按课程和学期汇总选退课与任课，避免把教师和排课明细直接乘进成绩计数。详细修订见[人工修改记录](人工修改记录.md)。
