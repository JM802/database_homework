# 范式与数据异常分析

候选键和逐表闭包计算见[函数依赖分析](函数依赖分析.md)。

## 1. 判定标准

- **1NF** 每个字段保留一个标量值。合授和多时段用多行表示。
- **2NF** 已满足 1NF，且每个非主属性完全依赖于每一个候选键。联合键逐项检查真子集。
- **3NF** 对任一非平凡依赖 X → a，X 是超键或 a 是主属性。若每个非平凡依赖的决定因素都是超键，还满足 BCNF。

## 2. 逐表判定

| 关系 | 1NF | 2NF 依据 | 3NF 依据 |
|---|---|---|---|
| 账号 | 满足，字段原子 | 满足，单列键 | 满足，A → role, hash 中的非平凡依赖均以候选键为决定因素 |
| 学生 | 满足，字段原子 | 满足，两个单列键 | 满足，S → A, name；A → S 中的非平凡依赖均以候选键为决定因素 |
| 教师 | 满足，字段原子 | 满足，两个单列键 | 满足，P → A, name；A → P 中的非平凡依赖均以候选键为决定因素 |
| 课程 | 满足，字段原子 | 满足，单列键 | 满足，C → name 中的非平凡依赖均以候选键为决定因素 |
| 学期 | 满足，字段原子 | 满足，任一键分量不能决定开学日 | 满足，Y,N → start_date 中的非平凡依赖均以候选键为决定因素 |
| 教学班 | 满足，字段原子 | 满足，单列键 | 满足，B → C,Y,N,capacity,active_count 中的非平凡依赖均以候选键为决定因素 |
| 上课时间 | 满足，字段原子 | 满足，自然候选键不能缩减，且全表字段均为主属性 | 满足，T → W,F,L；W,F,L → T 中的非平凡依赖均以候选键为决定因素 |

## 3. 逐表异常检查与处理

插入须引用已存在的资料、删除须遵守引用约束，是正常的业务完整性约束。下表说明分解后的插入和删除行为，以及更新时需要保障的独立事实。分解前的可复现异常见[关系分解](关系分解.md)。

| 关系 | 插入 | 删除 | 更新风险及处理 |
|---|---|---|---|
| 账号 | 可先初始化管理员；人员账号和档案成对创建 | 受档案引用限制，人员账号与档案一并清理 | 若在人员表复制角色或哈希，重置密码要改多处。现仅在账号更新。 |
| 学生 | 可先登记再选课 | 删档案前检查历史选退课 | 姓名只维护一份。新增学生须绑定账号，是必需联系。 |
| 教师 | 可先登记再安排任课 | 删档案前检查任课和改分引用 | 任课和改分记录只存工号，改名无需更新历史或任课。 |
| 课程 | 可先登记再开班 | 最后一个班删除后课程仍存在 | 能先建课程再开班。删班可保留课程，改课程名只更新一次。 |
| 学期 | 可先建立学期；小学期须有同年春季 | 删班不删除学期；学期只在独立管理范围内处理 | 开学日只有一处。结束日期按公式计算，减少维护同一日期事实的重复列。 |
| 教学班 | 班级与至少一条排课、任课同事务建立 | 删班回滚时关联数据必须一起恢复 | 删最后一班仍保留课程和学期，容量只在该班维护。人数缓存与选课记录跨表冗余，由事务控制。 |
| 上课时间 | 可预先登记公用时段 | 删排课不删共享时段 | 时段可先建立，由多个班复用。删排课不删时间定义。被引用的时间固定，另选或新建时间调整排课。 |
| 任课安排 | 班、教师存在后可单独新增联系 | 删班任课不删教师 | 可逐条维护任课关系。删除一班的一条任课不影响该教师身份及其他班。 |
| 选退课记录 | 重选以新编号追加，旧历史不阻塞 | 删班按需求清理该班历史 | 重选新增历史行，退课修改本次选课。课表、教室名称和人员资料保留在各自的关系中。 |
| 当前成绩 | 可先选课后录分 | 删除班时按依赖清理，缺考应为 0 分 | 可以还没有成绩行。改分仅更新成绩行，并将旧值和新值作为本次修改的快照写入历史。 |
| 成绩修改历史 | 一次真实改分可独立记录，首次录入无需历史 | 删班按依赖清理改分历史 | 新增修改历史无需复制当前分数和首录时刻。下一次改分不得覆盖已有历史快照。 |
| 教室 | 可预先登记房间 | 教室仍被引用时禁止删除 | 基础教室独立维护。调整显示名称不需要逐条更新排课。 |
| 教学班排课 | 教室、班和时间存在后登记具体安排 | 只清理目标排课，保留三端资料 | 改某班某次周排课的教室只改一行，其他班和共享时段不动。 |
| 班号发放计数 | 学期建立后可初始化为零 | 删班不删除或回退计数 | 删班时保留计数，不能通过现有班号的最大值重算。计数与建班处于同一事务。 |

## 4. 跨表一致性与查询口径

14 个关系按所列函数依赖也满足 BCNF。教学班人数缓存是 BR-11 要求的跨关系冗余。单行人数范围合法无法证明人数等于有效选课数，插入选课或退课必须同步更新该班人数，失败时一起回滚。

选课、任课和排课各可有多条。先按班分别统计，再按课程和学期组合，避免一次连接多个明细后重复计数。状态、退课类型、绩点、周课时和结束日按规则派生。固定节次的钟点定义由应用统一维护。班号发放记录不同于现存班号的最大值，删班时保留其已发状态。
