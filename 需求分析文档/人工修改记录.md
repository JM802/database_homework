## 2. 教学班、周次和成绩查询

| 项目成员发现的问题或提出的要求 | 修改结果 | 位置 |
|---|---|---|
| 选课结束后教师仍需查看任教班的学生名单和名额信息，学生端的限制不应套到教师端。 | 教师随时查看自己任教班的当前有效选课学生名单、容量、有效选课人数和剩余名额。学生仅在第 1 至 3 周看到三项名额信息和余量筛选。管理员可随时查询各班。 | FR-02、BR-05 |
| 同课各班应统一每周课时安排。AI 首次把要求写成各班每周上课时段相同。 | 经再次纠正，统一的是同课同学期各班的每周总课时数。具体时段可不同，时段重叠时教室及教师均不得重复占用，不重叠时可以复用。 | FR-01、BR-04 |
| 开学日期应为周日，从周日开始算一周。 | 第 1 周从开学周日开始，常规选退课到第 3 周周六结束。文档据此将第 10 周额外退课窗口写为周日至周三。 | FR-04、BR-07 |
| 成绩统计还应展示平均绩点和满绩人数。 | 增加平均绩点和满绩人数。按 90 至 100 分对应满绩的规则，把恰好 90 分的学生也计入。 | FR-06、BR-09、BR-10 |
| 管理员确定容量后不再调整。 | 创建教学班时录入正整数容量，创建后容量固定，删除原来的调低容量规则。 | FR-01、BR-04、BR-05 |
| 教学班查询先要求加入退课人数，随后确认这项统计不需要。 | 中间版本按退课学生去重展示人数，收到撤销要求后从列表、数据说明和验收规则中删除该项。课程统计仍按次数计算退课记录数。 | FR-02、第 5 节、BR-10 |

## 3. 对照审阅建议修正规则

| 项目成员发现的问题或提出的要求 | 修改结果 | 位置 |
|---|---|---|
| FR-03 的同课限制没有写清楚限于同一学期，与 BR-12 不一致。 | 两处都限定同一学生、同一学期、同一课程最多一个有效教学班。往期修读不阻止本学期选课。 | FR-03、BR-12 |
| 跨学期重修会令平均分、及格人数和去重口径不明确。进行中的人数也不宜叫“最终人数”。 | 成绩按单个教学班或“课程＋学期”统计。同一人两学期分别得 55、85 分时，各自只进入对应学期的统计。人数改称“当前有效选课学生人数”。 | FR-06、BR-10 |
| 已有学生选课的班停用后，原有退课、录成绩和人数统计可能无法处理。 | 有过选课记录的教学班及其所属课程不能停用，已退课的历史记录也触发保护。现有有效选课照常计入人数，并按原有退课和成绩规则处理。学生或教师停用时同步停用其账号，保留历史关联。 | FR-01、BR-13、第 7 节 |
| 选课后修改课程、学期或时段可能造成同课重复选课或课表冲突。教师、教室和开学时间也应固定。 | 有过选课记录后冻结所属课程、学期和固定节次。教学班创建后固定教师、教室和容量，学期创建后固定开学日期。 | FR-01、BR-04、BR-07 |
| 多时段和合授的占用关系不够明确。 | 全学期每周重复固定节次。早期按一班一个教室处理，现行规则改为每条排课指定教室。所有任课教师占用本班全部时段。项目范围排除单双周、分段周次和临时调课。 | 第 5 节、BR-04 |
| BR-11 仅明确选退课的回滚，成绩历史可能与当前成绩不一致。 | 更新当前成绩与写入修改历史在同一事务内完成，任一步失败全部回滚。选退课事务也明确有效人数始终等于有效选课记录数。 | FR-05、BR-11 |
| 分数从 1 开始，缺考没有对应值。 | 分数范围改为 0 至 100。缺考录入 0 分并计入统计，未录成绩显示“暂无成绩”且不计入平均值。 | BR-09、BR-10 |
| 恰好满 168 小时能否改成绩不明确。 | 以首次录入为起点，恰好 168 小时仍可修改，超过才拒绝。 | FR-05、BR-08 |
| “管理员固定密码”和“登录后可改密”有歧义，迭代次数要改回 600000 次。 | 管理员密码永久固定。学生和教师可改密，也可由管理员重置。哈希迭代次数改为 600000。 | 第 2 节、BR-03 |
